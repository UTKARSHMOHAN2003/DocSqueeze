# 📄 DocSqueeze – AI-Powered PDF Summarizer (SaaS)

DocSqueeze is a modern AI SaaS platform that allows users to upload PDF documents and receive accurate, concise summaries using Google's Gemini Flash 2.0 model. Built using the powerful Next.js framework, Prisma ORM, and SQLite, DocSqueeze is designed for speed, simplicity, and scalability. User authentication is handled by Clerk, and UploadThing is used for secure file uploads.

---

## 🚀 Features

- ✨ **AI Summarization**: Automatically summarize PDFs using **Gemini Flash 2.0**
- 🔐 **Authentication**: Secure user login/signup powered by **Clerk**
- 📤 **PDF Uploads**: Fast, secure PDF upload and storage using **UploadThing**
- 📚 **PDF History**: Users can view a list of their uploaded PDFs and summaries
- 🧠 **AI SaaS Architecture**: Scalable and modular design using modern web tools
